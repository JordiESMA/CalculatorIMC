# Calculadora de BMI (IMC)

Una aplicació d'Android desenvolupada amb **Kotlin** i **Jetpack Compose** que permet als usuaris calcular el seu Índex de Massa Corporal (IMC) de manera ràpida i interactiva.

## Característiques principals

* **Interfície intuïtiva:** Permet introduir el teu nom, ajustar el pes de forma senzilla amb botons de suma/resta, i seleccionar l'alçada mitjançant un control lliscant (*slider*).
* **Resultat al moment:** Calcula i mostra el valor del teu BMI juntament amb una salutació personalitzada.
* **Disseny adaptatiu:** La interfície suporta tant el mode clar com el mode fosc, adaptant-se a les preferències de l'usuari.
